# 数据结构 P1｜第 1–4 章：基础｜代码与习题

## 1. 算法复杂度：轮数与每轮工作分开算

手稿把 $2,4,8,\ldots$ 的倍增过程与 $n,n/2,n/4,\ldots$ 的折半过程并列。若每次乘或除以 $2$，规模到达 $n$ 或 $1$ 大约需要 $\log_2 n$ 轮。这只说明**轮数**；总时间还要计算每轮的工作量。

| 每轮工作量 | 总工作量 | 关键理由 |
|---|---|---|
| 常数 | $O(\log n)$ | 约 $\log n$ 轮 |
| 每轮都为 $n$ | $O(n\log n)$ | $n$ 重复约 $\log n$ 次 |
| $n,n/2,n/4,\ldots$ | $O(n)$ | 等比和小于 $2n$ |

最后一行可直接由

$$
n+\frac n2+\frac n4+\cdots<2n
$$

看出。它与“每轮都做 $n$ 次”不同，不能只看见折半就写 $O(\log n)$ 或 $O(n\log n)$。原图另有 $k^2<n$ 的演算，表示通过终止条件求出 $k$ 的量级为 $O(\sqrt n)$；这是另一类增长关系。

## 2. 双链表插入：先明确目标连接

原图用 A、B 之间插入 C 的箭头反复检查 `next` 和 `prior`。前置条件是 A 与 B 已相邻，且 A、B、C 都是有效结点。目标是 `A ⇄ C ⇄ B`，四条连接缺一不可。

```c
// 参考片段：调用前 a->next == b，b->prior == a。
c->next = b;
b->prior = c;
a->next = c;
c->prior = a;
```

复盘时先画出原连接，再逐条检查 A 的后继、B 的前驱、C 的前驱与后继。上面的片段只对应**B 存在**的情形；尾插、空表需要另按题设处理。

## 3. 表达式：先固定运算顺序

草稿中有中缀转后缀和表达式树的多次试画。两者检查的是同一件事：哪些运算先执行，哪些运算要等括号内或更高优先级的运算完成。

- 中缀转后缀：扫描操作数时直接输出；遇到运算符时按优先级和结合性处理栈顶；右括号触发括号内运算符出栈。
- 表达式树：操作数是叶子，运算符是内部结点；先确定子表达式，再连父子关系。
- 从表达式树读后缀式时按后序遍历，读中缀式时还需按原运算顺序补充必要括号。

原图中的具体字符和连线有覆盖，故这里保留可复用的检查步骤，不给某张试画指定唯一最终式。

新增草稿第 73 张给出明确的表达式 `(x+y)*((x+y)/x)`。外层运算为乘法：左子树对应第一个 `(x+y)`；右子树对应除法，除法的左子树是第二个 `(x+y)`，右孩子是 `x`。若画的是**表达式树**，两次出现的 `(x+y)` 各占一棵子树；若让两个位置共享同一个加法结点，得到的是可复用子表达式的有向无环图，而不是普通树。
