## 禁止提前扩写

以下内容尚无个人阅读与总结支撑，不得为「内容完整」提前填充：

- **四门课考点**（马原 / 毛中特 / 史纲 / 思修法基）：尚未开始系统学习，不得按大纲顺序预先铺开任一章节；次年集中学习时按实际进度建。
- **原典**（毛选 / 共产党宣言 / 资本论）：只写已读且自己总结过的部分，不代写全书提要、不补章节梗概。

- **未做过的题**：不写「标准答案」，未验证结论不标为正确。

## 学科既有约定

- **阅读笔记编码**：`POL-C<NN>-<Topic>-Reading`，与所读原书的章序一致。第一编「绪论」四章合为 `POL-C01-Intro-Reading`；后续按章顺延（第二编上古史第一章预留 `POL-C02-Origins-Reading`）。考纲笔记另入四个考纲目录。
- **两套分期不混写**：读原书时用吕思勉的分期；在本笔记里我自定为「1840 年前统称古代史」；凡涉及考点、答题或考点对照表，一律改用大纲分期（1840 / 1949）。
- **阅读优先级（约定，不是进度）**：中国通史 → 马列毛 → 世界通史 → 党纲 / 共产党宣言 → 次年集中学考研知识。资本论与经济学属兴趣自学，读到的内容同样进本仓库。
- **笔记形态**：读书总结与考纲笔记分轨；阅读笔记可附考点对照，但不能替代考纲笔记。外部补充与我的原话分栏，不混成一段。
