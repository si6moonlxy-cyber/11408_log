## 禁止提前扩写

以下内容尚无个人阅读与总结支撑，不得为「内容完整」提前填充：

- **未做过的题**：不写「标准答案」，未验证结论不标为正确。

## 学科既有约定

- **阅读笔记编码**：`POL-C<NN>-<Topic>-Reading` 中的章序跟随各自原书，文件名须能区分书名。现有 `POL-C01-Intro-Reading` 专属吕思勉《中国通史》第一编「绪论」四章；`POL-C02-Origins-Reading` 是该书第二编的预留名，不用于翦伯赞《中国史纲要》。考纲笔记另入四个考纲目录。
- **原书与考纲分期不混写**：读原书时保留各书的分期；已有吕思勉读书笔记中我自定为「1840 年前统称古代史」；凡涉及考点、答题或考点对照表，一律改用大纲分期（1840 / 1949）。
- **阅读优先级（约定，不是进度）**：先读翦伯赞《中国史纲要》，再读吕思勉《中国通史》；其后为马列毛 → 世界通史 → 党纲 / 共产党宣言 → 2027 年 7 月起集中学考研政治知识。资本论与经济学属兴趣自学，读到的内容同样进本仓库。
- **阅读复盘**：通史阅读以补历史基础为目的。每章先由我总结，再据此复盘；准备进入下一章时，可以先带着具体问题阅读。计算机类比只在确实有助理解时使用，不代替史料与论证。
- **笔记形态**：读书总结与考纲笔记分轨；阅读笔记可附考点对照，但不能替代考纲笔记。外部补充与我的原话分栏，不混成一段。
- **提示出现条件**：正文直接记录观点、依据和推理，不例行插入「已掌握」「待确认」「易错」等提示，也不另列未核实清单。只有来源差异、观点归属或考纲口径会影响判断时，才在对应处简短说明；未解决的细节先留在对话中，不写成结论。
