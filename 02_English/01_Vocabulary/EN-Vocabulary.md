# 词汇与构词线索

本页收录本次材料中的词，**不等于已核实的考研高频表**。先记现代词义和搭配，再用词源或词族帮助辨形；词源不是把现代拼写逐字拆开的公式。

## 本次词汇

| 词 | 词源或词族线索 | 现代核心义与用法 | 辨析点 |
|---|---|---|---|
| **precise** | 拉丁语 *prae-*（在前）+ *caedere*（切），经 *praecisus* 演变 | 精确的；`precise measurements` | 拼写是 `precise`，不要写成 `procise`；与 `precious`（珍贵的）分开。 |
| **contempt** | 来自拉丁语 *contemnere*（轻视）；其中的 *temnere* 不是现代英语 `tempt`（诱惑） | 蔑视、轻蔑；`contempt for` | `contemptuous` 指**表现出**轻蔑，`contemptible` 指**值得被**鄙视。 |
| **consequence** | *sequ-* 与“跟随”相关，可帮助记“随之而来的结果” | 结果、后果；`as a consequence of` | 常用于不利结果，但词本身不限定结果一定为负面。 |
| **confidential** | 与 `confide`、`confidence` 同词族，关联“信任” | 机密的、须保密的；`confidential information` | `confident` 是“有信心的”，不能用来修饰“机密文件”。 |
| **considerable** | 历史上有“值得考虑”的义项；现代词义已发展 | 相当大的、值得注意的；`a considerable amount of time` | `considerate` 是“体贴的”，不是“大量的”。 |
| **preach** | 源于拉丁语 *praedicare*（公开宣讲）；不能机械拆成现代英语 `pre + dica` | 布道；引申为说教；`practice what you preach` | 根据语境区分宗教讲道与带批评意味的说教。 |
| **receipt** | 与 `receive` 有历史联系，源于表示“收到”的拉丁语形式 | 收据；`a receipt for the payment` | `p` 不发音；`re + ceipt + t` 不是可靠的词根切分。 |
| **emerge** | 源于 *ex-*（向外）+ *mergere*（浸、沉） | 出现、浮现；`emerge from`；名词 `emergence` | 拼写为 `emerge`，不要加成 `emerage`。 |

## 易混词组

| 对照 | 区分方法 |
|---|---|
| **commerce / immerse** | `commerce` 是商业、贸易，词族联想到 `merchant`；`immerse` 是使浸入、沉浸，和 `emerge` 的“浸、沉”线索相关。两词的 `merc` 与 `mers` 不应混记。 |
| **polite / political** | `polite` 是礼貌的，历史上与“打磨、修饰”相关；`political` 是政治的，与城邦、公民的词族相关。字形相近，词源不同。 |
| **contrast / contrary** | 两者都有“相反”的线索；`contrast` 可作动词或名词，侧重比较差异；`contrary` 主要作形容词，表示相反的。 |
| **contact / contract** | `contact` 是接触、联系；`contract` 可指合同，也可作动词表示收缩。前者联系“触碰”，后者联系“拉到一起”。 |
