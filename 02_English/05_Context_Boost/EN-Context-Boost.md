# 发音复盘

本页只保留发音关注点。材料没有附原始录音，因此这些词是**待复盘材料**，不登记为“我已犯过的发音错误”。词义见 [[EN-Vocabulary]]；长难句见 [[EN-Syntax]]。

## 发音关注点

| 词 | 核对后的读音 | 复盘点 |
|---|---|---|
| `minute` | 名词“分钟”：英美均为 `/ˈmɪn.ɪt/`；形容词“极小的”：英 `/maɪˈnjuːt/`、美 `/maɪˈnuːt/` | 同形异音，先看词性与句意。 |
| `programming` | 英 `/ˈprəʊ.ɡræm.ɪŋ/`、美 `/ˈproʊ.ɡræm.ɪŋ/` | 注意 `gram` 与 `-ing` 之间的 `/m/`；拼写的双 `m` 不等于两个独立的 `/m/` 音。 |
| `prompt` | 英 `/prɒmpt/`、美 `/prɑːmpt/` | 词尾是 `/mpt/`，不要漏掉 `/p/` 或 `/t/`。 |

发音核对：[Cambridge minute](https://dictionary.cambridge.org/pronunciation/english/minute)、[programming](https://dictionary.cambridge.org/pronunciation/english/programming)、[prompt](https://dictionary.cambridge.org/pronunciation/english/prompt)。
