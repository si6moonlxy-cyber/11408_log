## 发音关注点

| 词 | 核对后的读音 | 复盘点 |
|---|---|---|
| `minute` | 名词“分钟”：英美均为 `/ˈmɪn.ɪt/`；形容词“极小的”：英 `/maɪˈnjuːt/`、美 `/maɪˈnuːt/` | 同形异音，先看词性与句意。 |

## 例句校对

### `like` 后接动词

材料原句：`I really like use them in my one task.`

可表达为：`I really like using them together in a single task.` 若强调习惯或选择，`I really like to use them together in a single task.` 也成立。

- `like use` 缺少合适的动词形式；`like + -ing` 和 `like + to-infinitive` **都可用**，不能只记成“like 后必须接 doing”。
- 若本意是“在同一个任务中使用它们”，`in a single task` 比原句的 `in my one task` 更明确。

语法依据：[Cambridge Grammar：like](https://dictionary.cambridge.org/grammar/british-grammar/like)。

### Codex 与 DeepSeek 场景

材料原句：`I usually make promote in Codex and do some really mask in deepseek.`

这句的 `promote`、`really mask` 无法仅凭现有文本可靠反推原意。**若**本意是“我通常在 Codex 写提示词，并在 DeepSeek 执行实际任务”，可表达为：`I usually write prompts in Codex and run the actual tasks in DeepSeek.` 是否确为原意，仍需原始语音或上下文确认。
