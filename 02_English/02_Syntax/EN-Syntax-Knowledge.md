# 语法基础知识

**例句与复盘：** [[EN-Syntax]]；**搭配与短语：** [[EN-Vocabulary-Phrases]]。

## 简单句与五种基本句型（Simple Sentences and Basic Clause Patterns）

找主干时，先问“谁或什么 + 怎么样”，再判断动词后面需要什么。主语（subject）可以是名词词组、代词或从句；手稿中的 `n. + v.` 是入门速记，不限制主语只能是一个名词。

| 句型 | 要检查的关系 | 手稿或课堂中的线索 |
|---|---|---|
| 主谓 S + V | 主体发生动作，不带直接宾语 | `sing`、`swim` 可以不及物使用。 |
| 主谓宾 S + V + O | 谁对谁／什么采取动作 | 找到动词后，再确认其对象。 |
| 主谓双宾 S + V + IO + DO | 给谁什么：间接宾语（indirect object）与直接宾语（direct object） | [[EN-Syntax#例句：给大象选择|They gave the elephants a series of choices.]] |
| 主谓宾补 S + V + O + OC | 宾语处于什么状态：宾语补足语（object complement）说明宾语 | [[EN-Syntax#例句：火灾与生态系统|fires made many ecosystems healthier]] |
| 主系表 S + V + SC | 主语是什么／怎样：主语补足语（subject complement），课堂称表语 | [[EN-Syntax#例题：缺少系动词|I am quite grateful ...]] |

五种句型是识别核心成分的入门框架，不是“每句话都只有这些成分”；地点、时间、方式等还可继续扩展。

### 及物与不及物用法（Transitive and Intransitive Uses）

及物用法带直接宾语，不及物用法不带直接宾语。判断的是当前句中的用法，同一动词可以有不同用法；“看中文动作能否独立完成”只能作提示，最终要核对英文搭配。被动句也不能硬补一个主句宾语，见 [[EN-Syntax#句 1：监控禁令及其结果]]。

### 双宾语与宾补（Two Objects and Object Complements）

双宾语中的两项指不同对象：`give somebody something` 是“给某人某物”。宾补则给宾语补充状态：`make ecosystems healthier` 中，变得更健康的是 `ecosystems`。不能看到两个动词后成分就一律叫“双宾语”。

部分双宾结构可以改成“直接宾语 + to/for + 接受者”，具体介词与能否改写取决于动词；本次只记 `give` 的例子，见 [[EN-Syntax#例句：给大象选择]]。

### 系动词与表语（Linking Verbs and Subject Complements）

系动词把主语与其身份、状态、特征联系起来。手稿将它归为“无实义”，便于区别动作动词；实际仍有“是、变得、保持、似乎”等意义。

| 本次手稿中的词 | 这里要识别的关系 | 边界 |
|---|---|---|
| `be` | 是／处于某种状态 | `be` 也可作进行或被动结构的助动词，须看后面的形式。 |
| `get / become / turn / go / grow` | 状态变化 | 同一词也可能有动作义，不按词表直接判句型。 |
| `look / sound / smell / taste / feel` | 看／听／闻／尝／感觉起来怎样 | 表感官状态时接表语；其他语境可有其他用法。 |
| `seem / appear` | 似乎 | 与后面的状态或判断结合看。 |
| `keep / remain` | 保持 | 此处记录系动词用法。 |
| `prove` | 结果证明是／显示为 | 可与 `prove something` 等及物结构区分。 |

## 谓语完整性与主谓一致（Verb Phrase Completeness and Subject–Verb Agreement）

谓语（verb phrase）可以由多个词组成。先找限定动词（finite verb，即带时态或情态、支撑当前分句的动词），再检查实义动词与必要成分；一个分句可以有并列谓语，不能机械记成“只能出现一个动词”。

| 检查点 | 判断方法 | 对应例题 |
|---|---|---|
| 缺少系动词 | 形容词描述主语时，句子是否有支撑判断的动词？ | [[EN-Syntax#例题：缺少系动词]] |
| 谓语多余 | 已有主动过去式，是否又误加了 `was`？ | [[EN-Syntax#例题：主动过去式前误加 was]] |
| 谓语不完整 | `-ing` 作进行谓语时，是否有相应的 `be`？ | [[EN-Syntax#例题：进行结构缺少 are]] |
| 主谓不一致 | 主语中心词是单数还是复数？是否又多加代词？ | [[EN-Syntax#例题：多余主语与主谓不一致]] |
| 缺少必要宾语 | 动词之后的成分是否真正构成其对象？ | [[EN-Syntax#例题：宾语名词缺失]] |

课堂五题是讲解示例，不能据此登记为你的个人错误。`be + -ing` 是进行结构、`be + 过去分词` 可构成被动；不能把所有多词谓语都当成“动词多余”。

## 一般时态与时间视角（Simple Forms and Time Reference）

本次只整理手稿与课件已经涉及的一般过去、一般现在、一般将来和过去将来。时态（tense）与时间概念有关，但形式与实际所指时间不总是一一对应；课堂“16 种”是时间视角与体（aspect）的教学组合框架，不在这里提前补全未学部分。

| 课堂名称 | 常见谓语形式 | 阅读时的问题 |
|---|---|---|
| 一般过去 | 动词过去式；`be` 用 `was/were` | 是否叙述过去的事件？手稿 `did` 是过去式速记，不是所有动词都改成 `did`。 |
| 一般现在 | 原形／第三人称单数 `-s`；`be` 用 `am/is/are` | 是否描述习惯、状态或一般事实？ |
| 一般将来 | `will + 原形`；`am/is/are going to + 原形` | 从当前视角看未来的预测、意图或安排是什么？ |
| 过去将来 | `would + 原形`；`was/were going to + 原形` | 是否从过去某个时间点看当时尚未发生的事？不能看见 `would` 就排除条件等其他含义。 |

课堂定位例句见 [[EN-Syntax#例题：用时间线索定位一般过去]]。本次截图未提供时态专项个人作答，不据此宣称已掌握全部形式。

## 长名词词组与主语中心（Noun Phrase Heads）

把主语压缩成中心词，再补回修饰。例如 `the terrific consequences of its tendency to discriminate` 的中心词是 `consequences`，`of ...` 解释哪一种后果；主干因此是 `consequences continue to vibrate`，不是“歧视”直接作主语。不能只摘名词猜句意，还要保留谓语的动作方向、否定和情态。

**对应练习：** [[EN-Syntax#句 1：研究、歧视倾向与社会影响]]、[[EN-Syntax#句 2：调查与资金储备]]。

## 从句与连接关系（Clauses and Linking Relations）

先确定分句边界和各自谓语，再判断从句承担主语、宾语、修饰还是状语作用。`although / even though` 表让步；`while` 可表时间、对比或让步，需结合上下文判断。`despite` 是介词，后接名词词组等成分，不与 `although + 完整从句` 混同。

`To what extent ... remains debatable` 的整个疑问内容在例句中作主语；它内部的谓语不能替代外层的 `remains debatable`。`that` 也须看依附关系，不能一律判为定语从句。

**对应练习：** [[EN-Syntax#句 2：学术剽窃的起因与评价]]、[[EN-Syntax#句 8：市场调查与短期利润]]、[[EN-Syntax#句 1：监控禁令及其结果]]。

## 非谓语与分词补充（Non-finite Forms and Participial Supplements）

`-ing` 不是“结果状语”的固定标记。先检查它依附名词还是补充整个事件，再结合语义判断关系。`threatening to shatter ... and shear off ...` 在既有练习中补充威胁，`ultimately instilling ...` 继续说明影响；两者不各自构成独立主句。`threaten to` 要保留风险、尚未实现的意味，不能直接译成已经摧毁。

`ultimately / fundamentally / therefore` 都是副词；其中 `therefore` 可表达逻辑结果，不能因此把它们统称为从属连词。

**对应练习：** [[EN-Syntax#句 1：研究、歧视倾向与社会影响]]、[[EN-Syntax#句 8：市场调查与短期利润]]。

## the 加形容词表示人群（The + Adjective）

某些形容词或形容词化分词可与 `the` 连用，指一类人，如 `the rich / the poor / the marginalized`。不是任何形容词前加 `the` 都能这样使用。`the marginalized` 是被边缘化的人群，不是地点“社会边缘”。

**对应练习：** [[EN-Syntax#句 1：研究、歧视倾向与社会影响]]；搭配 [[EN-Vocabulary-Phrases#instill A in B]]。

## 修饰语与动词搭配（Modifiers and Verb Patterns）

修饰语的词位会改变依附对象：`exerts force downward` 用方向副词修饰施力，`exerts downward force` 的形容词修饰 `force`。`like + -ing` 与 `like + to-infinitive` 都可以成立，不能简化为“like 后只能 doing”。

**对应案例：** [[EN-Syntax#案例：`downward` 的位置]]、[[EN-Syntax#`like` 后接动词]]。
