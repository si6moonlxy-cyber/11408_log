# 数据结构笔记使用方式

将本目录中的 Markdown 文件放入 Obsidian Vault 后，从以下两篇笔记进入：

- [[数据结构 Part 1｜知识主干]]：已整理的知识主干。
- [[数据结构 Part1｜代码与习题总结]]：从手稿提炼的推导逻辑、算法理解、题型方法与待确认内容。

手写原图单独保存在 `docs/computer_notes_shot/数据结构/` 的 ZIP 中；电子笔记不嵌入原图。原图的页码、文件名及主题可查阅该目录的 `原图清单.md`。总结中涉及的手写代码尚未验证，`[?]` 表示原图无法可靠辨认。

笔记里的部分双链指向计划后续建立的页面，目前仅作导航占位。
