## 1. 数据结构与算法基础

### 1.1 数据结构三要素

**数据结构 = 逻辑结构 + 存储结构 + 数据的运算**

逻辑结构可概括为：

```text
集合结构
线性结构
树形结构
图状结构
```

存储结构常见为：

```text
顺序存储
链式存储
索引存储
散列存储
```

### 1.2 算法与复杂度

算法分析主要关注：

- 正确性
- 可读性
- 健壮性
- 时间效率
- 空间效率

常见时间复杂度数量级：

$$
O(1)<O(\log n)<O(n)<O(n\log n)<O(n^2)<O(n^3)<O(2^n)<O(n!)
$$

## 2. 线性表

### 2.1 顺序表与链表

| 维度 | 顺序表 | 链表 |
|---|---|---|
| 存储空间 | 连续 | 可不连续 |
| 随机访问 | 支持 | 不支持 |
| 按位查找 | 快 | 需沿链遍历 |
| 插入/删除 | 常涉及元素移动 | 主要修改指针 |
| 空间分配 | 通常预分配 | 可按需申请 |

### 2.2 单链表

结点结构：

```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

结构示意：

```text
head
 ↓
[data|next] → [data|next] → [data|next] → NULL
```

### 2.3 双链表

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DLinkList;
```

结构示意：

```text
NULL ← A ⇄ B ⇄ C → NULL
```

### 2.4 循环链表与静态链表

- 循环链表：尾结点的指针重新指向头结点/头结点附近。
- 静态链表：使用数组下标模拟指针关系。

## 3. 栈、队列、数组与串

### 3.1 栈

核心特征：

$$
\text{LIFO}
$$

即**后进先出**。

典型应用：

- 括号匹配
- 表达式求值
- 递归
- 深度优先类过程

### 3.2 队列

核心特征：

$$
\text{FIFO}
$$

即**先进先出**。

```text
出队 ← front [A][B][C][D] rear ← 入队
```

### 3.3 串与模式匹配

重点：

- 串的基本概念
- 朴素模式匹配

## 4. 树与二叉树

### 4.1 树的基本概念

常见概念：

- 根结点
- 父结点 / 子结点
- 兄弟结点
- 叶子结点
- 结点的度
- 树的度
- 层次
- 高度 / 深度

树中：

$$
n = e + 1
$$

其中 $n$ 为结点数，$e$ 为边数。

### 4.2 m 叉树的常见结论

第 $i$ 层最多：

$$
m^{i-1}
$$

个结点。

高度为 $h$ 时最多：

$$
1+m+m^2+\cdots+m^{h-1}
=
\frac{m^h-1}{m-1}
$$

个结点。

### 4.3 二叉树性质

非空二叉树中：

$$
n_0=n_2+1
$$

其中：

- $n_0$：叶子结点数
- $n_2$：度为 2 的结点数

常见类型：

| 类型 | 记忆重点 |
|---|---|
| 满二叉树 | 每层结点数达到最大 |
| 完全二叉树 | 与满二叉树的编号位置对应 |
| 二叉排序树 | 左子树关键字小于根，右子树关键字大于根 |
| 平衡二叉树 | 左右子树高度差受约束 |

## 5. 二叉树遍历、线索二叉树、树与森林

### 5.1 遍历

```text
前序：根 → 左 → 右
中序：左 → 根 → 右
后序：左 → 右 → 根
层序：按层访问
```

记忆法：

> 前、中、后，说的是“根”的访问位置。

### 5.2 线索二叉树

常见结点结构：

```c
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;
} ThreadNode;
```

标志位：

```text
tag = 0 → 指向孩子
tag = 1 → 指向线索
```

线索用于记录：

- 前驱
- 后继

### 5.3 树与森林的表示

- 双亲表示法
- 孩子表示法
- 孩子兄弟表示法

孩子兄弟表示法核心：

```text
data | firstChild | nextSibling
```

## 6. 哈夫曼树

带权路径长度：

$$
WPL=\sum_{i=1}^{n}w_i l_i
$$

哈夫曼树的目标：使 WPL 最小。

构造过程：

```text
取权值最小的两个结点
        ↓
合并为新结点
        ↓
新权值 = 两者之和
        ↓
重新加入集合
        ↓
重复
```

## 7. 图

### 7.1 基本定义

$$
G=(V,E)
$$

- $V$：顶点集合
- $E$：边集合

常见概念：

- 有向图 / 无向图
- 简单图 / 多重图
- 完全图
- 子图
- 连通图
- 强连通图
- 连通分量
- 强连通分量
- 度 / 入度 / 出度

无向图：

$$
\sum_{v\in V}D(v)=2|E|
$$

有向图：

$$
\sum ID(v)=\sum OD(v)=|E|
$$

### 7.2 图的存储

- 邻接矩阵
- 邻接表
- 十字链表
- 邻接多重表

### 7.3 图的遍历

**BFS**

- 常借助队列
- 按层扩展

**DFS**

- 常借助递归或栈
- 沿一条路径深入后回溯

## 8. 最小生成树

### 8.1 Prim

记忆：

> Prim 更像“扩点”。

基本过程：

```text
从一个顶点开始
      ↓
维护已选顶点集合
      ↓
选择连接集合内外的最小权边
      ↓
加入新顶点
      ↓
直到包含全部顶点
```

### 8.2 Kruskal

记忆：

> Kruskal 更像“选边”。

基本过程：

```text
边按权值升序排列
      ↓
从小到大尝试加入
      ↓
若形成环则舍弃
      ↓
直到选出 n-1 条边
```
